# 任务：基于以下信息，产出一份投递建议

请严格按以下步骤执行，只依据给定信息，禁止编造简历内容：

步骤 1【定结论】比较简历与 JD，三选一给出结论：建议投 / 不建议投 / 先补再投。并给出 0–100 的匹配分数。

步骤 2【找理由】给出 3 条理由。每条必须：引用 JD 原文用词（加「」）+ 引用简历原句或字段（加「」），说明匹配或不匹配。

步骤 3【找差距】列出具体差距，例如「缺一个能量化的项目」「缺团队协作证据」。禁止写「需要提升综合能力」这类空话。

步骤 4【给建议】给出本周可执行的一件具体事。

步骤 5【写招呼】写一句用这家公司语言风格的打招呼第一句（使用企业文化标签中的词）。

## 输入

候选人画像：

{{PROFILE_JSON}}

岗位需求分析：

{{JD_ANALYSIS_JSON}}

企业价值观分析：

{{COMPANY_VALUES_JSON}}

## 规则

- 结论三选一：建议投 / 不建议投 / 先补再投。
- 每条理由必须同时引用 JD 原词与简历原句。
- 差距必须可对应到具体补救动作。
- 招呼语使用企业文化标签中的词。
- 上游缺字段时在 note 中说明，不补编内容。

## 输出格式

严格输出 JSON，不要包含任何其他解释文字：

```json
{
  "position": "岗位名",
  "conclusion": "建议投|不建议投|先补再投",
  "score": 78,
  "reasons": ["理由1", "理由2", "理由3"],
  "gaps": ["具体差距1", "具体差距2"],
  "advice": "本周可执行的一件具体事",
  "opening_line": "打招呼第一句",
  "note": ""
}
```
