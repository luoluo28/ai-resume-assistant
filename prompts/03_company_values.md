# company_values — 企业价值观分析

输入占位符：`{{COMPANY_TEXT}}`（公司官网 about/价值观页文本）、`{{JD_TEXT}}`（岗位描述原文）

---

# 任务：分析这家公司的企业价值观，并反推简历应对策略

请严格按以下步骤执行，只依据给定文本，禁止推测：

步骤 1【摘原文】从「公司官网文本」中摘出与价值观、文化、用人观直接相关的原句，逐条列出，并标注是原文原话。

步骤 2【归纳标签】把步骤 1 的原句归纳成 3–5 个文化标签，每个标签一句话概括，并在其后附上步骤 1 里对应的官网原句作为佐证。

步骤 3【映射能力】针对每个标签，反推「简历里应提供什么行为证据」才能对上该标签，给出具体可写的证据方向（例如某次协作方式、某段抗压经历）。

步骤 4【给证据建议】综合以上，用一句话回答：这家公司会录用什么样的人。

## 输入

公司官网 about / 价值观页文本：

{{COMPANY_TEXT}}

岗位描述（JD）：

{{JD_TEXT}}

## 规则

- 每个标签必须有官网原句佐证（source 字段填原句）。
- 禁止凭公司名气推测文化。
- 只有 JD 无官网时，允许最多 2 条 jd_inferred 标签并标注来源。
- 缺官网文本时，need_company_info = true，不输出标签。

## 输出格式

严格输出 JSON，不要包含任何其他解释文字：

```json
{
  "need_company_info": false,
  "labels": [
    {"tag": "...", "source": "官网原句", "resume_evidence": "简历应提供的证据方向"}
  ],
  "hire_profile": "这家公司会录用 ______ 的人"
}
```
